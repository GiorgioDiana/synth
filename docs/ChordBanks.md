## Voicings

Written keeps each curated voicing. Close compacts the existing voices while retaining doubled pitch classes. Open spreads alternate voices; Drop2 lowers the second-highest voice. Rotate1/2 move the lowest one/two existing voices upward. Rotations of rootless chords remain rootless; these labels do not claim a particular harmonic inversion. At MIDI limits, whole voicings shift by octaves to retain all notes.

## Musical use

Chorale banks use four-part spacing and functional harmonies, but arbitrary key order is not an automatic counterpoint generator. For ChoraleI in C, try input C3 → D#3 → E3 → C3 for C → F → G7 → C. Evans-inspired rootless banks intentionally omit chord roots and suit playing with a bass instrument. Choose rooted jazz banks for full solo sonorities.

Chord palettes and synth sound patches are independent. Changing a sound patch preserves the chord bank; changing the harmony bank affects the next trigger while held chords release their original notes correctly.
